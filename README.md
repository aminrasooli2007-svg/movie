# 🎬 Movie — Movie Website

A modern and responsive movie website built with **HTML5 and CSS3**, featuring a clean layout, movie cards, and a visually engaging interface.

## ✨ Features

- 🎥 Movie-focused website design
- 🖼️ Movie cards with image assets
- 📱 Responsive styling for different screen sizes
- 🎨 Custom styling with CSS
- 🧩 Organized HTML and CSS files
- 💻 Simple and lightweight frontend implementation

## 🛠️ Built With

- **HTML5** — Website structure
- **CSS3** — Styling and layout
- **Responsive CSS** — Mobile-friendly styling

## 📂 Project Structure

```text
movie/
├── asset/
│   └── images/
│       └── cards/
├── index.html
├── style.css
├── mobile.css
└── README.md
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aminrasooli2007-svg/movie.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd movie
```

### 3. Run the website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
